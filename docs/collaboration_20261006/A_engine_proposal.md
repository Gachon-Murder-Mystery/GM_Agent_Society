# GM 진행 상황 공유 및 엔진 연결 방식 협의 제안

수신: 이재형님 · 게임 엔진 담당(A)

작성: 박천웅 · GM 및 GM↔agent 상호작용 담당(C)

작성일: 2026년 10월 6일

재형님, GM 쪽에서 준비한 내용과 다음 연결에서 같이 맞춰 보고 싶은 부분을 정리했습니다. 저는 여러 agent가 같은 사건에서 움직이고, 엔진의 결과를 각 agent와 GM이 같은 의미로 기록하는 흐름을 염두에 두고 작업했습니다. 아래 항목은 현재 확인한 main을 기준으로 생각해 본 연결 제안입니다. 이미 준비 중인 기능이나 다른 연결 계획이 있다면 그 방식을 먼저 공유해 주시면, GM 쪽 입력·출력을 맞춰 보겠습니다.

## 제가 염두에 둔 흐름과 작업 범위

게임은 이동 → 탐문·탐색 → 추리의 세 단계로 진행하고, agent는 엔진에 직접 행동을 요청하는 흐름으로 준비했습니다. GM은 캐릭터 배분, 단계 시작과 상황 안내, 전원 완료 확인, 정보 소유 기록, 장애 조정을 담당하도록 분리했습니다. 주사위·직업 보너스·정보 공개 판정·공식 상태 변경은 엔진에서 결정한 결과를 받는 방식입니다.

GM은 모든 agent가 얻은 정보를 감독 목적으로 기록하되, 다른 agent에게 전달할 내용은 명시적으로 공유된 정보로 구별해 두었습니다. 그래서 제 쪽에서는 ‘누가, 어느 단계에서, 어떤 행동으로, 어떤 정보 ID를 얻었는지’를 식별할 수 있는 엔진 결과가 중요한 연결 자료가 됩니다.

## 현재 GM 쪽에서 진행한 내용

| 준비한 영역 | 현재 확인한 범위 | 다음 연결에서 남은 부분 |
|---|---|---|
| 캐릭터 배분 | 데모·룰북 기반 임시 직업/성향/선택 목표를 가변 인원에게 조합하는 코드 | 엔진이 제공할 정의와 등록 방식에 맞추기 |
| 단계 진행·상황 안내 | 모의 엔진에서 위치 안내, 허용 행동 안내, 전원 소비 후 단계 전환 | 실제 엔진의 단계·소비 상태와 연결 |
| 정보 원장·공개 범위 | 모의 엔진에서 개인 소유, GM 감독 기록, 명시적 공유를 분리 | 실제 결과·감독 상태를 수신하고 대조 |
| 장애·사망·대리 GM | 모의 환경에서 NPC/시체 구분, 감독 기록 인계와 전환 호출 지점 | 실제 엔진 제어 접점과 런타임 전환 연결 |
| 실제 코드의 부분 연결 | B의 오프라인 파서 → A의 실제 함수 → C 관찰 저장기로 단서 2개 전달 확인 | 자율 다중 agent와 실제 GM 제어로 확장 |
| 메시지 의미 대조 | 카탈로그 ID 일치, 이동·준비·지목 본문 3개의 왕복 변환, 획득 단서 의미 보존 확인 | 팀의 실제 메시지 송수신에 같은 의미가 유지되는지 확인 |

부분 연결은 사람이 정한 입력과 고정 주사위로 확인했습니다. 실제 자율 플레이, 다중 agent의 한 사이클, 실제 장애 감시는 아직 확인하지 못했습니다. GM 코드가 실제 엔진을 제어한 전체 연결까지 진행된 상태는 아닙니다.

## 상호작용은 이렇게 준비하고 있습니다

정상 agent 간에는 ‘GM 안내 → 질문 agent가 엔진에 요청 → 상대 agent가 공개/거절 판단 → 엔진 검증·판정 → 질문자와 GM이 같은 결과 수신’을 작업 전제로 두었습니다. 상대의 응답은 자기 이동·탐색·추리 행동을 추가 소비하지 않는 수신 처리로 생각하고 있습니다. NPC와 장애 NPC는 엔진의 수동 정책으로, 시체는 주사위와 잔존 정보로 처리하는 구분입니다.

이 전제를 반영하는 데 엔진 구조상 다른 전달·대기 방식이 더 적절하다면 어떤 구성이 좋을지 의견 부탁드립니다. 저는 엔진 판정이나 B의 응답 로직을 변경하기보다, 제공되는 접점에 GM 안내·감독 수신을 맞추고 싶습니다.

## 먼저 같이 확인해 보고 싶은 작은 연결

같은 사건에 2명 이상을 연결해 이동 → 탐색 → 추리 생략 한 사이클을 먼저 돌려 보면 어떨까요? 단서를 얻었다면 엔진 결과, agent 기억, GM 원장에 같은 정보 ID가 남는지 보고 싶습니다. 단서가 없는 결과와 생략도 완료로 집계하고, 같은 요청의 재전송은 추가 소비가 없는지 함께 확인하면 연결 기준을 구체적으로 맞출 수 있을 것 같습니다.

제가 제안한 메시지 이름을 그대로 사용할 필요는 없습니다. 같은 사건·행위자·행동·단서·완료·공개 범위를 연결할 수 있는 재형님의 기존 형식을 알려 주시면, 대응표와 GM 어댑터를 조정하겠습니다. 우선 현재 가능한 접점과 준비 중인 접점, 편한 전달 방식, 제안 순서에 대한 의견을 부탁드립니다.
