# 담당자별 GM 연결 협의 자료

2026-10-06 기준. 작성자는 박천웅(C)이며 실제 메시지 발송 전 검토·전달할 수 있는 문서다.

| 전달 대상 | 편집 가능한 전달 문서 | 저장소에서 검토할 원문 | 포함 작업 |
|---|---|---|---|
| 이재형님 · 엔진(A) | [엔진 연결 협의 제안서](A_engine_proposal.docx) | [Markdown 원문](A_engine_proposal.md) | A01–A12 |
| 황규한님 · agent(B) | [에이전트 연결 협의 제안서](B_agent_proposal.docx) | [Markdown 원문](B_agent_proposal.md) | B01–B10 |
| 두 담당자 공통 | [GM 진행·공통 협의 제안서](GM_common_proposal.docx) | [Markdown 원문](GM_common_proposal.md) | C01–C08, D01–D08 |

각 문서는 단독으로 전달해도 GM의 작업 전제·범위·진행 수준, 다음 연결에 필요한 기능과 선결 조건, 담당자의 현재 방식·대안을 묻는 내용이 읽히도록 작성했다. 공통 문서는 함께 공유할 진행 설명이며 개별 제안서에 첨부할 수 있다. 우선순위와 접점은 협의용으로 표현했고, 현재 GM의 게임 흐름과 상호작용 전제는 이를 구현하는 전달 방식·메시지·대기 방식과 구별했다.

이 제안서는 업무 배정이나 담당자의 동의를 기록한 문서가 아니다. 협의 후 실제 접점과 작업 순서를 정하고 GM 측 계약·어댑터를 갱신하기 위한 자료다.

기술 근거: [역할별 작업·선결 조건](../../ROLE_TASKS_20261006.md), [공통 언어 대조](../../SHARED_LANGUAGE_20261006.md), [현재 입출력 계약](../../IO_CONTRACT.md).

DOCX 재생성: 워크스페이스 루트에서 `python -m gm_coordinator.build_collaboration_documents`. 원문 변경 후 다시 실행한다.

검증 기록은 `verification.json`에 있다. 총 38개 항목, 원문 본문의 DOCX 보존, 파일/XML 구조와 표 열 수를 확인했다. Word 자동화가 완료되지 않아 Word 화면의 페이지 배치는 확인하지 못했다. 검토용 Markdown 원문을 함께 제공한다.
